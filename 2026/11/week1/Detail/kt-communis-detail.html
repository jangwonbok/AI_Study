Overview

KT Communis는 클라우드 플랫폼을 통해 통신 기능을 제공하는 서비스입니다. 그에 맞는 핵심 정보를 메인 최상단에 배치하여 효율적으로 정보를 전달합니다. 또한 다양한 종류의 API를 시각화하여 표현함으로써 서비스에 대한 이해도를 높여줍니다.

The Approach
UX Concept Building

복잡한 통신 API를 누구나 한눈에 이해하는
서비스 경험으로.

Challenge

  • 통신 API라는 낯선 개념을 처음 방문한 고객에게 설명해야 함
  • 문자·알림톡 등 API 상품 종류가 많아 정보가 분산됨
  • 사업자·기획자·개발자마다 필요한 정보가 다름

Objective

  • 핵심 정보를 메인 최상단에 배치해 효율적으로 전달
  • 다양한 API를 시각화해 서비스 이해도 향상
  • 웹과 모바일에서 일관된 경험 제공

Solution

  • 사용자 유형별 3개의 진입 카드
  • API 상품별 아이콘·일러스트 시스템
  • 이용 절차의 단계형 시각화와 콘솔 대시보드
