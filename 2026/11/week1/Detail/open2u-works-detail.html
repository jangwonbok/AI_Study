Biz.파트너와의 동반성장을 추구하는 SKT Open2U 구매시스템 리뉴얼 사이트로, T컬러의 아이덴티티를 활용하여 사용자가 보다 간결하게 업무 프로세스를 이해할 수 있도록 심플한 레이아웃과 뚜렷한 그룹핑을 통해 사용성을 높이고 UI를 시각적으로 개선시켰습니다.

  1. Point 01T컬러 아이덴티티SK telecom의 T컬러를 시스템 전반의 시각 언어로 확장했습니다.
  2. Point 02심플한 레이아웃업무 프로세스를 한눈에 이해할 수 있도록 화면 구성을 단순화했습니다.
  3. Point 03뚜렷한 그룹핑정보 단위를 명확히 묶어 탐색과 입력의 사용성을 높였습니다.
  4. Point 04시각적 UI 개선아이콘·컬러·타이포 체계를 정비해 UI 완성도를 끌어올렸습니다.

SCM 우체통,
의견이 닿는 4단계

협력사의 의견 등록부터 SCM그룹장 보고까지, 복잡한 처리 흐름을 단계와 담당 주체 중심으로 재구성해 누구나 진행 상황을 예측할 수 있게 했습니다.

적합 → 담당 팀장 전달 부적합 → 회신 및 종료
  1. Step 1 · 협력사의견 등록Open2U 로그인 없이도 의견을 작성할 수 있습니다.
  2. Step 2 · SCM기획팀적합성 검토적합한 의견은 담당 팀장에게 전달하고, 부적합 시 사유를 회신한 뒤 종료합니다.
  3. Step 3 · 담당 팀장검토결과 답변최대 14일 이내에 검토 결과를 답변합니다.
  4. Step 4 · SCM기획팀SCM그룹장 종합보고처리 결과를 종합해 SCM그룹장에게 보고합니다.
